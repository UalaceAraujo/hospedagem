# Sistema de Hospedagem - .NET

Projeto desenvolvido para o desafio da Trilha .NET da DIO. O sistema simula um gerenciamento de hospedagem em um hotel, permitindo o cadastro de hóspedes, configuração de suítes e o cálculo de valores de diárias com regras de desconto.

## Tecnologias Utilizadas
- .NET 8
- C#
- Git

## Funcionalidades
- Cadastro de pessoas (hóspedes).
- Cadastro de suítes com validação de capacidade.
- Regra de negócio para desconto de 10% em estadias superiores a 10 dias.
- Menu interativo via console para gerenciar as operações em tempo real.
